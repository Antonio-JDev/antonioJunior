# Pasta do Currículo (CV)

## 📄 Como adicionar seu CV

1. **Coloque seu arquivo PDF do currículo nesta pasta**
2. **Renomeie o arquivo para:** `cv-antonio-junior.pdf`

OU

3. **Mantenha o nome que preferir e atualize o caminho no código:**
   - Abra o arquivo `components/Hero.tsx`
   - Localize a prop `cvUrl` e atualize o caminho

## 📌 Exemplo

Se seu arquivo se chamar `meu-curriculo.pdf`, o caminho seria:
```
/portfolio-01/assets/cv/meu-curriculo.pdf
```

## ⚠️ Importante

- O arquivo deve estar em formato **PDF**
- Mantenha um nome sem espaços ou caracteres especiais
- Recomendado: não ultrapasse 2MB de tamanho
